
# Snap Strip

A free photobooth web app. Take 4 photos with a countdown, pick a filter
and strip colour, add a caption, and download your photo strip as a PNG.

**Live demo:** https://snap-strip-delta.vercel.app/

## Features
- Camera with a 3-2-1 countdown and flash
- Black & white and warm filters
- 5 strip colours and a custom caption
- Upload photos instead of using the camera
- Download the strip as a PNG

## Built with
HTML, CSS and JavaScript (no frameworks). Uses the browser camera API.

## Run it locally
Download `index.html` and open it in Chrome.
